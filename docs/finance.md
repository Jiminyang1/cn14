# 财务模型（2026-10-17）

这次修改重建了收支与资产的记账方式。旧文档里的 `SAVE_BASE`、`WEALTH_MPC`、`RET_DRAW`、`PAR_DRAW` 和欠款冻结公式已经停用。存档格式从 7 升到 8，旧格式需要重新开始；过往人生记录保留。

## 口径：年还是月

钱的量只有两种口径，混用就会出错（原来对象的「收入不错」把年收入 `p.inc` 又乘了 12，几乎人人都算收入不错）：

- **按年**：记在人物身上、或者描述一个人「挣多少、领多少、要付多少」的量，一律是一年的。`S.income`（税前）、`S.net`（到手）、`p.inc`（对象、配偶，税前）、`S.pension`、`flags.rehire.inc`、`parentIncome()`、`myPay()` / `matePay()` / `partnerPay()` / `parentPay()` 返回的 `gross`、`net`，地点的 `placeInc()`、`placeCons()`，名字带 `Y` 的（`careFeeY`、`kidSupportY`、`oldIncomeY`、`dibaoStdY`）。
- **按月**：只有三类。月底结算里算出来的这个月的量（`moneyMonth`、`familyMoneyMonth` 里的局部变量），账单 `MonthlyStatement` 里的每一项，以及名字里写明「月」的（`monthlyPay()`、名字带 `M` 的变量和参数，如 `incM`、`DIBAO_M`）。
- 比较、相加之前先换到同一个口径：年 ÷ `MONTHS` 得月，月 × `MONTHS` 得年。显示用 `wanM(年)`、`perMo(年)`，它们自己除以 12，传进去的必须是一年的量。
- 存量（`money`、`debt`、房价、欠款）没有口径，和「一年的收入」比的时候直接比，例如「欠款超过一年收入」。

## 现金、债务和房产

- `money` 是可用现金，不小于零；`debt` 是其他欠款。事件支出超过现金的部分记为欠款，现金收入先到账，月底再按实际余额还债。
- 房贷单独记余额、剩余期数和逾期额。每月先计息，再用公积金和现金实付；没有付款就不能减少贷款余额，贷款到期也不会自动清零。逾期额已经包含在余额中，计算净资产时不能重复扣。
- 继承先结清遗产内的债务。现金到账，房产另记为权益；明确选择出售后才变成现金，按估值的 95% 到账。完整产权可以选择搬入，共有份额不能直接当作自己整套住房。
- 净资产 = 现金 − 其他欠款 + 公积金 + 自有住房估值 + 继承房产权益 − 房贷余额。它不等于能立刻花的钱。

## 每月生活开销：分档

本人和父母用 `budget.ts` 的同一套规则。一家人一个月的生活开销 = 当地人均月消费 × 家里人数 × 档位倍数。大人算 1 个，孩子 6 岁前 0.35、18 岁前 0.5、读大学 0.6。

| 档位 | 开销（当地人均消费的几倍） | 收入达到当地人均消费的几倍才过得上 |
|---|---|---|
| 拮据 | 0.85 | — |
| 普通 | 1.05 | 1.15 |
| 小康 | 1.45 | 1.6 |
| 宽裕 | 2.05 | 2.3 |
| 富足 | 3.0 | 3.4 |

- 「收入」是一个月到手的钱，再加上存款的 6%（一年）÷ 12：存款多的人家日子过得更好，钱不会只攒不花。
- 每年过生日那个月定一次档；档位变了，时间线上写一句（「手头宽裕了些，周末敢下馆子了」）。退休以后收入少了，一年最多往下退一档。
- 开销里约当地人均消费 × 人数 × 0.55 是必要的，钱不够就记缺口（触发「手头紧了」）；其余只从余钱里出，不借钱。住养老院的，费用里包了吃住，不再另付生活开销。
- 先不做的：可选消费、孩子的单独开销、动用积蓄这些细项。以后有了玩家主动花钱的玩法、孩子的系统，再从生活开销里分出去。

月末顺序：家里的往来、收入和公积金、必要的生活开销、住房（房租或养老院、房贷）、欠款利息和还款、档位里其余的开销、存款利息。存款按年 1.5%、其他欠款按年 4% 计息。

## 账本

「我的经济」先是你自己的现金、这个月的收支和档位，成家以后是「我的小家」，最下面是父母家（折叠）。「收支账本」经济独立以后才出现，每个月一张账单，只有几行：

```
期末现金 = 期初现金 + 到手收入 − 生活开销（档位） − 房租／养老院 − 房贷 − 还欠款 + 其他（事件、家里的往来、利息）
```

为零的行不显示。公积金直接还的房贷、欠款新增的利息不从现金扣，账单下面用一句话带过。大事记里每个年龄年结束后有一条「年终小结」，展开看逐月账单。

## 彩礼（2026-10-17）

你自己结婚和兄弟姐妹结婚用同一套规则（`kin.ts` 的 `famPayBride`、`sibWed`）：娶亲的，父母在世就由家里出彩礼，不够的部分父母去借，记成家里的欠款；父母都不在了才自己出。出嫁的，彩礼一半做陪嫁进你的存款，另一半留在娘家；父母都不在了，整笔做陪嫁。酒席的钱自己出。原来男主角一律自己出，婚后欠着钱的男主角 54%，其中父母存款超过 10 万的 38%；现在分别是 9.4% 和 5.3%（婚前就欠着钱的 12%）。

## 晚年的开销（2026-10-17）

- **养老院包吃住。** 住养老院时不再另扣大人的基本生活（原来费用和基本生活都扣，每月多扣约一份基本生活）。费用每人每年约当地人均可支配收入的一半（`CARE_K`，估计），老伴还在的两个人一起住、交两份。
- **去不去养老院看付不付得起。** 费用减去养老金、子女给的、老伴的收入，差的部分靠积蓄；撑不到两年的不能选，撑得越久越愿意去，撑满 9 年（80 岁左右的余寿，估计）和收入够付的一样。原来权重固定，付不起的也住进去，欠款一直累积到去世。
- **住院走医保。** 「住了一次院」按 2024 年全国医院次均住院费用 9,870 元（卫健委统计公报）扣掉医保的实际报销（`health.ts` 的 `reimburse`），自付中位约 4,400 元；原来是当地人均收入的 0.2 倍（中位约 1 万元）、不看医保。

校准（money 2000）：离世时欠着钱 11.3% → 9.4%；死时欠钱的人 55 岁以后养老院欠费 4.6 万 → 0.4 万。各年龄现金中位数基本不变，超过 1000 万仍是 0.45%。

还没处理、留着的：住进养老院的人仍有 13.4%（付得起的人多，比例主要由抉择的基础权重决定，现实里在院老人只占很小一部分，需要另找数据校准）；70 岁还在城里租房的占活到 70 岁的四分之一，其中付不起的多是进城务工、工厂工人、个体户出身，退休后回不回老家的抉择不看付不付得起；欠亲戚的钱也按年息 4% 计息，占剩下欠款的约四分之一。

## 手头紧了（2026-10-17）

原来缺钱时只有房贷断供会弹出抉择；看病透支、房租和养老院付不起欠下的钱，玩家没有任何办法，只能挂在账上按 4% 计息。死时欠钱的人里四成名下还有房、八成有在世的子女，现实里他们会卖房、搬去和子女住、向子女开口。规则在 `tight.ts`，抉择在 `content/decisions.ts` 的 `tight`。

- **触发**：连续 3 个月手头紧（付不起基本生活或房租，或者欠款还在涨），且欠款至少是当地人均可支配收入的一成，或者正付不起开销；每 12 个月最多一次；房贷断供时由 `arrears` 处理，不再问这个。
- **选项按处境出现，每一项都有代价**：
  - 卖房还债（有房；以后租房住，幸福 −6）；换一套小点的房子（自住、没有房贷；换成约六成价钱的房子，差价还债，幸福 −3）。
  - 找爸妈要钱（父母在世、45 岁以前、父母有余钱且不欠钱；父母最多拿出现金的一半，钱从父母账上转过来，遗产跟着变少）。
  - 搬去和子女一起住（60 岁以上、有成年子女；不再付房租）；跟子女开口（退休、有成年子女；子女先垫最多三年的生活费，之后从每月给你的钱里扣回）。
  - 搬回自己在别处的房子 / 回老家（不上班，在别处有房或不在户籍地）。
  - 再出去找点活干（退休、70 岁以前、身体还行）。
  - 节衣缩食（还清以前基本生活少花两成，幸福 −2）。
  - 申请低保（家庭人均收入低于当地标准、没有房产、存款不超过一年的低保金；按差额补到标准，每月重新核对，不符合就停发）。2025 年 5 月底全国城乡低保平均标准每人每月 799.7 元、594.9 元（民政部）。
  - 先扛着。
- **自动抉择的权重**大多是估计：卖房是最后一招，欠得越多越可能卖；约 41% 的老人和成年子女同住（CHARLS），所以有子女的老人搬去同住、开口都常见；在别处有房的搬回去最省钱；年轻人最常见的是找父母要钱。

校准（money 2000，前 → 后）：离世时欠着钱 9.4% → 6.0%，一生中欠款超过当地 10 年收入 0.20% → 0；各年龄现金中位数略低（30 / 50 / 70 岁 6.3 / 24.9 / 65.2 万 → 6.0 / 24.3 / 59.6 万：找父母要的钱从父母账上出，遗产少了），超过 1000 万 0.45% → 0.50%。3000 局里死时欠钱的 265 → 158 人，欠款中位 3.7 → 1.1 万。弹出频率每 100 个成年人年 2.1 次，约一半的人一生里遇到过；30 岁前的多是没找到工作和销售行情差的年份。density：各年龄段每年的抉择数增加 0–0.05 个。选得最多的是先扛着（38%）、节衣缩食（28%）、找父母要钱（15%）、低保（7%）。

还没做：把房子租出去、自己租便宜的住（需要租金收入），工作年龄的人回老家（要连着换工作）。
