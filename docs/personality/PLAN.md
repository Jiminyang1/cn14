# 性格：计划

## 为什么要加

现在一个人只有四项状态（健康、幸福、学识、人际）和处境（家境、学历、职业、钱、家人）。两个处境一样的人，在模拟里就是同一种人，只差运气。对象的「性格」（温和、直爽……）只是一个标签，不影响任何事。

## 调研结论（三份调研，2026-10）

1. **心理学数据**（大五人格的元分析、CFPS 2018 的大五题目）：
   - 性格大约四成来自遗传；5 岁时几乎看不出将来，25 岁以后基本稳定（相隔 10 年的相关约 0.6，相隔 50 年仍有约 0.5）。
   - 随年龄「成熟」：20→60 岁，敏感 −0.6 个标准差，认真 +0.5，随和 +0.4。女性比男性敏感约 0.35 个标准差（CFPS 夫妻样本 0.34），其他维度在中国样本里男女差别很小。
   - 影响最大的结果：幸福（敏感 −、外向 +、认真 +）、离婚（敏感 +、随和 −、认真 −，每个标准差的风险比约 1.15 / 0.85 / 0.85）、成绩（认真 β≈0.25）、死亡（认真 0.89、敏感 1.05）、抽烟（敏感 1.19、外向 1.16、认真 0.88）、搬去外地（开放性、外向，约 1.15–1.3）。
   - 很小、可以不做的：收入（每个标准差 2–3%）、**性格相似度对婚姻的影响（解释不到 0.5%）**、**性格对「坏事之后恢复多快」的调节（基本没有）**。
   - 伴侣之间性格的相关只有 0.06–0.16。
2. **其他游戏**（模拟人生、十字军之王、RimWorld、矮人要塞、1in8b 等）：
   - 常见做法：童年在几个固定节点被环境和经历塑造，然后「定型」并明确告诉玩家；
   - 自动 / AI 决策按性格加权（十字军之王）；
   - 违背性格的选择不禁止，而是有代价（十字军之王的压力）；
   - 同一件事对不同性格写不同的话、悼词里体现性格。
   - 常见的坑：性格太多记不住（矮人要塞），只是标签没作用（模拟人生 4）。
   - 1in8b 也有隐藏的「气质」（2–5 岁形成，四选一），但它的自动抉择不看气质。
3. **代码**：
   - 自动抉择（`autoPick`）和随机事件（`chooseEvent`）各只有一个入口，加权只要改一处。
   - 出生时主随机数流是连着用的，多抽一次后面就全变了，所以性格用单独的随机数流。
   - 童年抉择选了什么记在 `flags.kid`，还没有任何地方用。

## 定下来的设计

### 五条轴

用连续值（大致是标准分数，人群平均 0、标准差 1），界面上只显示词。

| 键 | 正向 | 负向 | 对应 |
|---|---|---|---|
| `e` | 外向 | 内向 | 大五 E |
| `n` | 敏感 | 心大 | 大五 N |
| `c` | 认真 | 随性 | 大五 C |
| `a` | 随和 | 要强 | 大五 A |
| `r` | 敢闯 | 求稳 | 风险偏好（不用开放性 O：O 对收入、健康几乎没影响，它起作用的地方——搬家、创业、炒股——本来就是风险决策） |

和原先说的 4 条相比多了「随和」：调研里它对离婚（r −0.18，和敏感一样大）和婚姻满意度（CFPS 里最大）的影响最明显。界面上只显示离中间最远的一两个词，所以五条也不会难记。

### 怎么形成、怎么变

每条轴由三部分组成：

- **天生** `g`：出生时抽，不变。
- **经历** `k`：童年的抉择和环境一点点推，有上限（±0.5）。
- **起伏** `u`：每年生日变一次。年度自相关小时候低（约 0.7），25 岁以后约 0.88。

「天生」的权重从出生时约 0.4 升到 25 岁约 0.7，其余由「起伏」补足，保证总方差约为 1。这样成年后相隔 1 年的相关约 0.9（真分数，没有测量误差），相隔 10 年约 0.6，相隔 50 年约 0.5，童年到成年约 0.3。

对结果起作用的是 `z = 天生 + 经历 + 起伏`，它在每个年龄、每个性别里都是平均 0（等于用「同龄同性别里的相对位置」去算）。所以人群的平均寿命、结婚率等不会因为加了性格而整体偏移。

界面上显示的词另外加上「成熟」和性别差（敏感随年龄下降、认真和随和上升、女性敏感 +0.35），所以同一个人年纪大了，词可能会变。

- 随机数：用第三条随机数流 `rnd3`（种子派生，和 `rnd2` 同样的做法），包括出生时抽「天生」、每年的「起伏」，所以主流的随机数序列不变。
- 对象 / 配偶的性格：把原来的 `pick(TRAITS)` 换成一次 `rnd()` 做种子派生 5 条轴（主流消耗次数不变），和你的性格相关约 0.12。对象的性格固定不变，原来的 `trait` 标签由轴派生。
- 旧存档：不做兼容（游戏还没发布）。人生对象的结构变了就把 `SAVE_FORMAT` 加一，旧存档直接作废。

### 第一步接入（这次做）

| 地方 | 做法 | 系数（每个标准差） |
|---|---|---|
| 幸福目标值（`stats.ts drift`） | 加减 | 敏感 −2.5、外向 +1.2、认真 +0.8、随和 +0.4。成年人幸福的标准差约 8，相当于 β −0.3 / +0.15 / +0.1 |
| 人际目标值 | 加减 | 外向 +2.5、随和 +1 |
| 健康目标值 | 加减 | 认真 +0.8 |
| 自动抉择（`autoPick`） | 选项加 `tilt`，权重 × e^(Σ tilt·z) | 每个抉择逐个写倾向，大多 0.3–0.6 |
| 自动抉择的理由 | 倾向起了明显作用时，在记录下面加一句小字，比如「向来求稳」 | — |
| 认识人 | 概率 × e^(0.25·外向) | — |
| 对方愿不愿意 | +0.04·外向 | — |
| 恋爱中的感情 | 目标值：敏感 −2、随和 +1.5（双方各算一次） | — |
| 分手 | × e^(0.2·敏感 − 0.15·随和 − 0.1·认真) | — |
| 离婚 | 双方各 × e^(0.14·敏感 − 0.16·随和 − 0.16·认真) | 按风险比 1.15 / 0.85 / 0.85 |
| 童年塑形 | 9 个童年抉择的选项各推一点（例如「挣脱大人的手跑过去」外向 +0.15）；留守敏感 +0.15、父母离异敏感 +0.1；被欺负敏感 +0.1 | 「经历」上限 ±0.5 |
| 定型 | 7 岁（一年级上学期末）发一份「小学成绩报告单」，班主任评语按性格写；时间线上记一句 | — |
| 界面 | 页头一两个词；「概况」页加五条带词的刻度（不显示数字）；恋爱卡、抉择卡片显示对方的性格词；结局页履历加「性格」 | — |

所有乘法加权都做均值修正：用 e^(k·z − k²/2)，保证人群平均不变。

### 第二步（之后）

- 随机事件按性格加权（`chooseEvent` 一处），例如抽烟、被骗、打架、升职、炒股。
- 抽烟（敏感 1.19、外向 1.16、认真 0.88）、死亡（认真 0.89、敏感 1.05，要扣掉抽烟已经带来的部分）。
- 中考、高考（认真）、去大城市和跳槽（敢闯）、储蓄率（认真 +、敢闯 −）、工资（±3%）。
- 自动选每年的重心按性格。
- 裁员名单里的选项：`turns.ts` 正在被另一个会话改，等它合并。
- 手动选了和性格相反的选项：选项上用小图标提示「会憋屈」，选了扣一点幸福。
- 文字回响：同一件事按性格写不同的话，每隔几年一条性格回响，悼词体现性格。

### 故意不做的（和理由）

- **「敏感的人坏事打击更大、恢复更慢」**：数据说性格基本不调节事件冲击和恢复速度（Yap、Anusic & Lucas 2012），敏感只通过更低的幸福目标值起作用。
- **「性格越像越合得来」**：相似度对婚姻满意度的解释不到 0.5%。对方的性格只通过他 / 她自己的敏感、随和起作用。
- **性格标签很多、能自选**：太多记不住；我们是看着一生过去的游戏，性格要通过「他自己会怎么选」表现出来。

## 校验

1. 用开关 `PERS.on = false` 跑快照测试，必须和现在的 golden 完全一样（证明主随机数流没被动过），然后再打开、重建快照。
2. 重跑 `sim`、`marr`、`love`、`stats`、`mortk`：平均寿命、结婚比例、离婚、各年龄幸福的均值，和现在相比偏差在几个百分点以内。
3. 性格本身的检查（新脚本 `calib -- pers`）：
   - 各轴的均值和标准差；
   - 成年后 1 年、10 年的相关；
   - 敏感和幸福、外向和人际的相关（目标约 −0.3、+0.3）；
   - 离婚率按性格分组的比值。
4. 浏览器里玩一局：页头的词、概况页的刻度、7 岁的成绩报告单、自动抉择的理由。

## 第一步的结果（2026-10-16）

**性格本身**（`npm run calib -- pers 3000`）：
- 30 岁时各轴的均值在 −0.06 到 +0.11 之间，标准差约 1。敏感偏高 0.11，来自童年塑形里留守、被欺负这类经历。
- 稳定性：相隔 1 年 0.94，10 年 0.65，30 年（30→60 岁）0.5，童年到成年（8→30 岁）0.37。
- 和状态的相关：45 岁时敏感与幸福 −0.24、外向与幸福 +0.18、认真与幸福 +0.13，外向与人际 +0.32。
- 离婚过（活到 60 岁的人）：按「敏感 − 随和 − 认真」分组，低组 21.5%、中组 23.8%、高组 29.2%。
- 32 岁未婚：内向的 23.5%，外向的 15.1%。

**校准**：

| 项目 | 关掉性格 | 打开性格 |
|---|---|---|
| 平均寿命 男 / 女 | 75.6 / 81.3 | 75.1 / 81.1 |
| 学历、职业、人均孩子数、各年龄平均幸福 | — | 基本不变（幸福约低 0.3–0.5） |
| 住过大城市 | 59% | 56% |

平均寿命是 6000 人的结果，误差约 ±0.3。

**唯一调过的参数是认识人的频率**：
- 原因：外向的人认识人多、内向的少，每个人的倍数平均是 1。但「到 32 岁结没结婚」对认识人的频率是凹的，人和人一不一样，整体结婚的就少了：32 岁未婚男 22.0% → 28.0%，女 8.3% → 16.0%。另一半原因是敏感的人更常选「再处处看」。
- 判断：这是真实的效应，内向的人确实更可能不婚。所以不去掉，而是调基准，把总量对回普查。
- 调整：`MEET_K` 1 → 1.3，`MEET_KF` 0.8 → 0.95。结果男 23.9%、女 9.5%（普查 20.6% / 9.3%，原来校准到 23.9% / 9.4%），初婚年龄 28.1 / 25.2。

**做了的接入**：
- 幸福、人际、健康的目标值；
- 自动抉择：34 个抉择里 55 个选项有倾向，理由写在记录下面；
- 认识人、对方愿不愿意、恋爱中的感情、分手、离婚；
- 对象的性格（由主流的一次 `rnd()` 派生）；
- 童年塑形：9 个童年抉择、留守、被欺负；
- 小学成绩报告单；
- 界面：页头、概况页的刻度、恋爱卡、同伴、结局页。

**没做的**：
- 父母离婚对性格的影响：父母离婚的判定在 `kin.ts`，另一个会话在改。
- 填志愿时服不服从调剂：在 `education.ts` 里用 `chance(0.9)` 判定，要接性格得多抽一次随机数。
- 买房、生孩子、治病：主要看钱和身体，没有加倾向。
