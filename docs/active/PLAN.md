# 主动选择：计划

> 总原则见 [AGENTS.md](../../AGENTS.md)：好玩优先，现实数据是参照。

## 为什么要加

现在玩家能做的只有两件事：每年选一个时间重心，和在关口上回答弹出来的抉择。其余的都自动发生。这一轮排查里看到的问题，根子都在这里：

- **重心的效果太小，也太孤立。** 9 个重心，整年都花在一项上也只有状态 ±5，而且除了「工作」（涨工资）和「恋爱」（认识人）以外，不连着任何结果。玩家感觉不到自己的安排起了作用。
- **钱没有用处。** 消费只看收入，存款多少不影响体验，也解锁不了什么，所以钱只会越攒越多（`docs/finance.md`），玩家也不在乎怎么安排钱。
- **很多该自己拿主意的事是直接发生的。** 买车、炒股、旅游、随份子、住院等 15 个改钱的事件不经过选择；缺钱时原来只有房贷断供会问（「手头紧了」已补上）。
- **家人只有在不在、病没病，没有亲疏。** 子女给多少钱、谁来照顾父母、遗产怎么分，都和你平时怎么对待家人无关。
- **自动抉择时，界面上的重心和实际结算的不是同一个。** `planYearSchedule` 为显示抽一次（`S.focus`），`autoMonth` 为结算又抽一次（`fAuto`）：200 局里 83% 的月份两者不同。

## 调研结论

### 其他游戏（2026-10-17）

| 游戏 | 主动行动怎么做 | 怎么防刷 | 可以学的 / 要避开的 |
|---|---|---|---|
| BitLife | 一年里活动菜单随便点 | 几乎没有 | 反面教材：刷健身、找父母要钱；菜单层层嵌套；很多选择没有后果 |
| 1in8b.life | 每年一个重心加关口抉择，有自动决定 | 每年一个 | 和我们现在一样薄 |
| 人生重开模拟器 | 开局分一次点数，之后全自动 | 只有开局 | 社区很快总结出「家境和体质最重要」这种单一最优解 |
| 中国式家长 | 每回合排日程，再用行动力做事 | 行动力有限，学多了压力大，下回合行动力少 | 有张力的分配；后期变成固定套路 |
| 模拟人生 | 实时操控 | 一天 24 小时，需求条衰减 | 关系衰减太快变成打卡，很多玩家装 mod 关掉 |
| Stardew Valley | 每天的时间加体力 | 送礼每周 2 次 | 运气由种子加日期决定，读档刷不出不同结果 |
| 十字军之王 3 | 同时只有一个生活方式重心，换重心有冷却 | 时间就是预算；违背性格的事加压力 | 低频但有分量的长期选择；好感由带时效的修饰组成 |
| Reigns | 每张卡二选一 | 四条数值太高太低都会死 | 决策快、每个选择都有取舍 |
| Long Live the Queen | 每周选两门课 | 时间固定 | 心情影响学习效率；检定看不见只能查攻略（要避开） |
| Kudos | 每天做一件事，朋友会来约 | 体力和疲劳 | 「累了要不要拒绝朋友」这种日常取舍 |

结论（对我们这个「真实数据、时间自动流动、确定可重放」的游戏）：
1. **一个统一的时间预算**，所有主动行动都从里面扣，不做无限菜单。上学、上班先占掉一块，剩下的自由时间按时间利用调查给默认分配。
2. **不操作也合理**：每项都有按人设生成的默认值，玩家只调偏差。
3. **边际递减，再叠加状态**：同一项投入越多收益越少；健康、心情影响效率。防刷，也逼玩家做组合。
4. **关系只给少数核心人物数值**，衰减要慢到不变成打卡，而且要兑现成具体结果（借钱、照顾、养老、遗产）。
5. **理财只问低频决策**（配置比例、买房借贷这种时点），不做高频交易，不能成为稳赚的印钞机。
6. **每个选择至少牺牲一样东西**；性格让不同的人代价不同，避免单一最优解。
7. **按子系统分开随机数**：一个选择不扰动其他系统，读档刷不出不同结果。
8. 要避开：活动可以随便刷、菜单堆砌、选择没有后果、单一最优解、看不见的检定、维护数值变成打卡。

- 经常锻炼的人 38.5%（2025）。
- 职业证书的工资效应：只有小样本研究，中级及以下约 +11%、技师及以上约 +25%（可信度低，用时标估计）。志愿服务实际参与率查不到。

**顺带发现、和现有规则对不上的两处**（另外修，不在这个模块里）：
- 存款利息按年 1.5%（`finance.ts` 的 `SAVE_INT_M`），而现在一年期定存是 0.95%、货基约 1%。
- 退休后子女每人每年给「当地人均消费 × 0.35」（`tight.ts` 的 `kidSupportY`，人均消费 3 万的地方约 1 万元，两个子女约 2 万），而调查里收到子女钱的老人平均每年约 4100 元，还有三成多的老人收不到。

### 代码

- 重心有 9 项，按月记时间账（`S.fT`），每月结算 1/12 年的效果；读的地方只有 `focus.ts`、恋爱（认识人 ×1.5、感情目标 +8 / 工作 −4）、工作涨工资。改成时间分配，牵动面小。
- 玩家输入只有五种（抉择抽签、抉择、改重心、开关自动、自述），都走 `game/replay.ts` 的 `applyInput`；加一种 `act` 就能把主动行动纳入重放。
- 钱只有现金、欠款、房子、公积金四样，没有投资账户；家人除了配偶的「感情」，没有亲疏数值。
- 自动抉择时界面显示和结算的重心不一致（见上），重构时一并修掉。

## 设计原则

1. **玩家要感觉得到。** 安排了什么，这一生就要看得出不一样：遇到的事、走到的结果。效果宁可大一点。
2. **每个选择都有代价**（时间、钱、健康、关系），没有永远正确的一项。
3. **不操作也合理。** 每一项都有按处境和性格给的默认值，玩家只改想改的。
4. **能重放。** 玩家的每个主动操作都是一条输入（局日志），引擎按输入确定地推进。
5. **不刷。** 主动操作都消耗这一年有限的时间或钱，做不完所有事。
6. **不打断。** 主动操作在玩家想做的时候做，不额外弹窗；不操作也能过完一生。

## 四块

### 一、年度时间安排（重构「重心」）

（2026-10-17 和用户定下：格子要少，一次性的事不占格子。）

**格子。** 6–17 岁 **1 格**，18 岁起 **2 格**；6 岁以前没有（由大人带着）。两格可以放两件不同的事，也可以都放同一件（全力投入，第二格效果打折，边际递减）。

**放什么。** 沿用现在的选项：学习、玩耍（18 岁以前）、朋友、运动、工作、恋爱（单身时）、家人、爱好、养身体。效果比现在大，并且连着具体结果：学习 → 成绩、考证；工作 → 升职涨薪，代价是健康和家人；家人 → 亲疏（见二）；运动、养身体 → 健康；朋友 → 人际、认识人。

**重心改变这一年会遇到什么事。** 每个随机事件打一个领域标签（恋爱、工作、家庭、健康、社交、学习），重心所在领域的事件被抽中的权重提高（倍数按玩起来的感觉定）。两条原则：
1. **好事坏事一起变多**：恋爱 → 心动、约会多了，吵架、分手也多了；工作 → 升职多了，过劳、职场冲突也多了。是取舍，不是单纯加成。
2. **每年的事件总数不变**：还是每年 2–3 个随机事件的位置，重心只改变抽到哪类事，不会变吵。
一部分抉择也挂上去：工作 → 更容易被挖、有升职机会；恋爱 → 认识人更多（现在已是 ×1.5）。

**一次性的事不占格子**：回家看看、旅行、给家人钱等放在「行动」里，靠花钱和每年的次数上限来限制（见二、三）。

**默认分配。** 每年自动按处境和性格给一份，玩家只改想改的；不操作也合理。自动抉择时就用这份，显示的就是结算的（修掉现在 83% 不一致的问题）。

### 二、人际

**亲疏。** 父母、兄弟姐妹、子女各有一个亲疏值（配偶已有「感情」），不联系会慢慢变淡，衰减要慢到不变成打卡。离得远是最大的因素：同县的子女一年见父母 123 次、县外只有 10 次。

**行动：**
- 打电话、视频（几乎不花钱，效果小）。
- 回家看看（一年有次数上限；离得远要路费）。
- 给钱：给父母、给成年子女（金额自定，真实从账上转过去）。
- 接父母来同住 / 搬去子女那边（已有的抉择接上亲疏）。
- 带家人去旅行（和三里的旅行合并）。

**兑现成结果（接进已有规则）：**
- 子女每年给你多少钱：按亲疏和子女自己的收入，自动时对上「65.6% 收到、平均约 4100 元」。
- 父母病了谁照顾、「搬去和子女住」能不能选、老房子怎么分（兄弟姐妹里谁和父母亲）。
- 晚年社会隔离对健康的影响（HR 1.22）。

### 三、活动

一次性的行动，有花费、有次数上限或冷却，不占格子：
- **旅行**：国内（每次约 970 元，按当地收入缩放）、出境（贵得多）；幸福、人际，带家人去加亲疏。自动时按「每人每年约 4 次出游」（老年人只有 9% 出游）的比例。
- **学技能考证**：报名花钱，还要连续几年把一格放在「学习」上，考下来加薪。
- **健身卡、兴趣班**：按月花钱，配合「运动」「爱好」重心效果更好。
- **体检**：早发现大病的机会（需要数据支持再做）。
- **买车、装修**：大额开销，替代「动用积蓄的花销」那个按比例扣钱的旋钮。
- 现在自动发生的旅游、买车事件改成这里的行动；自动抉择时按处境和性格替你做。

### 四、理财

**在「经济档案」弹窗里做**（会暂停游戏），只问低频决策：
- 把钱分成几份：活期（0.05%）、定期（约 1%）、银行理财（约 2%）、指数基金（按沪深300）。以后加保险。
- 每年按配置比例自动再平衡，玩家随时改比例。
- **行情**：未来每年的指数涨跌，从 2005–2025 的真实逐年序列里有放回地抽（保留大涨大跌的年份）。按公历年份抽、所有人生共用同一条行情——同年出生的同伴经历同一轮牛熊；另开一条随机数流，不扰动其他系统。
- **自动策略**：按家庭金融资产配置的典型比例（存款、定期为主，股票基金一成上下），钱越多、「敢闯」越高，风险资产越多。
- **不能是印钞机**：只有指数，不能选股；没有杠杆；行情真实，长期年化约 7%、21 年里 10 年下跌。

## 交互入口和节奏

- 主界面「四、本年度时间安排」改成 1–2 个格子：一眼看到今年的重心，点一下调整（按月结算，随时可改，和现在一样）。
- 一个「行动」入口，打开会暂停的单子，分「人际 / 活动」两栏；理财在「经济档案」里。每个行动写清楚占几格、花多少钱、有什么用。
- 不在年初强制弹窗；需要时可以加一个默认关闭的「新的一年怎么安排」提醒。## 技术约束

- 新的输入类型 `act`（行动名 + 参数），和抉择、改重心一样走 `applyInput`，重放时逐条复现。
- 新的随机数要么放进主流（快照整体会变），要么另开一条流（比如市场行情），按需要定。
- 每一块都要加无界面时的自动策略；做完跑一下 `npm run calib -- sim` 体检，看有没有离谱。
- 人生对象的结构会变：`SAVE_FORMAT` 加一，不做旧存档兼容。

## 分步

1. **年度时间安排重构**：1–2 个格子、默认分配、效果连着结果、重心改变事件倾向；修掉自动时显示和结算不一致。其他模块都从这份时间里扣，先做。
2. **人际**：亲疏、行动、接进已有规则；子女给多少钱看亲疏。
3. **活动**：旅行、考证、买车装修；替代「动用积蓄的花销」。
4. **理财**：账户、行情、自动配置；顺手把存款利率对上现在的水平。

每一步做完都从头到尾读几局完整的人生，用「真人玩法」脚本（像之前「总是拒绝」那样）看玩家体验。
