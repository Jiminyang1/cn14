# 14亿分之1

随机出生在中国的某个角落，过完只有一次的一生。纯前端，无需构建。

## 运行

```
python3 -m http.server 8714
```
然后打开 http://localhost:8714 。直接双击 index.html 也能用。

## 结构

- `js/data.js`：31 个省份的出生人数、城镇化率、预期寿命、收入、房价等（约值，正式发布前需核对）
- `js/engine.js`：出生抽签、逐年推进、生命表死亡判定、收入开销、同一秒出生的 4 个同伴
- `js/content.js`：随机事件 `EVENTS` 和抉择 `DEC`（中考、高考、毕业去向、考公、35 岁、彩礼、买房、生育、照顾父母、治病……）
- `js/ui.js`：首页、出生卡、一生、结局

## 加一个事件

在 `EVENTS` 里加一行：

```js
{ id: 'xxx', a: [最小年龄, 最大年龄], w: 权重, c: () => 条件, once: 1, run: () => { eff({ h: 2 }); return '发生了什么'; } }
```
